1. このアプリでできること

Splice や自分のフォルダにあるオーディオサンプルを、探して、聴いて、Pro Tools のトラックへ置くアプリです。VoiceOver とキーボードだけで使えるように作っています。

  • サンプルのフォルダを登録してスキャンすると、中の音（WAV・AIFF・FLAC・MP3・OGG）を一覧にします。Splice のフォルダなら、パックごとに分けて探せます
  • ファイル名・種別（ワンショットかループか）・モノラルかステレオか・パック・お気に入り・カテゴリ・タグで絞り込みます
  • 一覧でスペースを押すと試聴、リターンを押すと Pro Tools へ置きます。置く先のトラックは、アプリの中から選んでおけます
  • Pro Tools のセッションのテンポとキーを教えておくと、置く前に素材を移調し、長さを合わせます。どう加工した音になるかは、置く前に試聴できます
  • ループを「4 小節おきに 4 個」のように並べて置けます

結果は、VoiceOver が読み上げます。時間のかかる操作（スキャンと配置）は、始まりと終わりを短い音でも知らせます。

3. 入れ方

3.1 アプリを置く

  1. 受け取った zip ファイルを Finder で開きます（選んでコマンド+O）。同じ場所に「PTサンプルマネージャ_1.1.0」というフォルダができます
  2. フォルダの中の「PTサンプルマネージャ.app」を、アプリケーションフォルダへ移します。Finder で .app を選んでコマンド+C、アプリケーションフォルダでオプション+コマンド+V（移動）です
  3. マニュアルなどの文書は、どこに置いてもかまいません

3.2 初めて開くとき

このアプリは、Apple による公証（ノータリゼーション）を受けていません。そのため、インターネットから受け取った zip から取り出したアプリを初めて開くと、macOS が開くのを止めることがあります。そのときは、次のどちらかで開きます。

方法 1: システム設定から開く

  1. アプリを一度開こうとします。開けないという知らせが出たら、「完了」で閉じます
  2. システム設定の「プライバシーとセキュリティ」を開き、下のほうの「セキュリティ」へ進みます。PTサンプルマネージャ の使用がブロックされたという文と、「このまま開く」のボタンがあります
  3. 「このまま開く」を押し、パスワード（または Touch ID）で認めます
  4. もう一度アプリを開き、確かめる知らせが出たら「このまま開く」を選びます

macOS の版によって、文やボタンの名前が少し違うことがあります。2 回目からは、ふつうに開けます。

方法 2: ターミナルで隔離の印を外す

アプリをアプリケーションフォルダへ移してから、ターミナルで次の 1 行を実行します。

xattr -dr com.apple.quarantine "/Applications/PTサンプルマネージャ.app"

インターネットから受け取ったファイルに付く「隔離」の印を外す命令です。外したあとは、ふつうに開けます。

3.3 ffmpeg と rubberband（加工するとき）

セッションのテンポとキーに合わせる加工（9 章）と、モノラルとステレオを変える変換（8 章）は、ffmpeg を使います。rubberband もあれば、テンポとキーの加工はそちらを使い、音質が上がります。どちらも Homebrew で入れます。ターミナルで次の 1 行を実行します。

brew install ffmpeg rubberband

アプリは、Homebrew の置き場所（/opt/homebrew/bin と /usr/local/bin）から探します。入れたあとは、アプリを開き直します。どちらを使うかは、セッションの条件の画面（コマンド+S）のいちばん下に書いてあります。探す・聴く・加工しないで置くだけなら、どちらも要りません。

3.4 macOS が許可を求めてきたとき

  • 書類・デスクトップ・ダウンロードのフォルダや、外付けのドライブにあるサンプルをスキャンすると、「PTサンプルマネージャ が … のファイルへのアクセスを求めています」と聞かれます。「許可」を選びます。許可しないと、そのフォルダの音を読めません
  • 「System Events を制御する」許可を求められることがあります。読み上げの予備の方法のためで、許可しなくても使えます

4. はじめに: サンプルのフォルダを登録する

アプリを開くと、ファイル名の検索欄にフォーカスがあります。初めは一覧が空なので、まずサンプルのフォルダを「読み取り先」として登録し、スキャンします。

  1. コマンド+F で「読み取り先フォルダの管理」を開きます。フォルダのパスの欄にフォーカスがあります
  2. フォルダのパスを入れます。タブで「フォルダ選択ダイアログを開く」のボタン（画面の文字は「フォルダを参照」）へ移ってリターンを押すと、フォルダを選ぶ画面からも選べます。Splice のフォルダは、ふつうはホームフォルダの「Splice」です（~/Splice と入れてもかまいません）
  3. 名前の欄は、空欄ならフォルダの名前になります。種類は、Splice のフォルダなら「Splice（パックごとに分ける）」、それ以外は「通常のフォルダ」です。フォルダを選ぶ画面で選ぶと、中を見て自動で選びます
  4. パスか名前の欄でリターンを押すと登録します（「入力した内容で読み取り先を登録する」のボタンでも同じです。画面の文字は「この読み取り先を追加」）。「「Splice」を追加しました」のように読み上げます
  5. エスケープで閉じ、コマンド+R でスキャンします。音の数が多いと、数分かかることがあります。終わると件数を読み上げ、一覧に出ます

読み取り先はいくつでも登録できます。Splice と自分の素材のフォルダを分けて登録しておくと、コマンド+数字で切り替えて見られます（6 章）。

スキャンのしかた

  • 読み取り先の選択肢で 1 つを選んでいるときは、そのフォルダだけをスキャンします
  • 「すべての読み取り先」のときは、登録したフォルダを全部スキャンします
  • 読み取り先が 1 つも無いときだけ、スキャンするフォルダを選ぶ画面が出ます

スキャンは何度してもかまいません。登録済みの音は飛ばし、増えた音だけを足します。外付けのドライブが外れていてフォルダが見つからないときは、低い音を鳴らして「[警告] …（フォルダが存在しません）」と読み上げます。

読み取り先を外すには、読み取り先の管理で一覧から選び、「一覧で選んだ読み取り先を外す」のボタン（画面の文字は「選んだ読み取り先を外す」）を押します。確かめる知らせが出るので「はい」を選びます。そのフォルダから登録した音も一覧から消えます（ファイルそのものは消えません）。

6. 探す

6.1 検索と絞り込み

検索条件の欄を入れて、検索欄（カテゴリとタグの欄でも）でリターンを押すか、「検索を実行」を押します。見つかった数を読み上げ、0 件なら低い音を鳴らします。条件はすべて同時に満たすものを探します（かつ）。

  • ファイル名: 一部分で探します。大文字と小文字は区別しません。日本語のファイル名も探せます。日本語入力のまま全角で打っても見つかります
  • 種別: ワンショットだけ・ループだけ。スキャンしたとき、ファイル名に loop・ループ・groove・beat などがあればループ、それ以外はワンショットにしています。違っていたら直せます（10 章）
  • チャンネル構成: モノラルだけ・ステレオだけ
  • 読み取り先: 登録したフォルダのどれか、またはすべて
  • パック: Splice の読み取り先のパック。中の音の多い順に並び、それぞれの件数を読みます。いまの条件に合うパックだけが並ぶので、選べば必ず結果があります。種別などを変えて、選んでいたパックが条件に合わなくなると、そのことを読み上げて絞り込みを外します
  • お気に入りだけを表示: 入れると、その場で検索し直します
  • カテゴリ: 名前がぴったり同じものを探します。タグ: カンマで区切って複数書くと、全部を持つものを探します

6.2 一覧の読み上げ

検索結果一覧で上下矢印を押すと、1 行ずつ読み上げます。順番は、ファイル名、お気に入りなら「お気に入り」、種別、BPM、キー、長さ、サンプルレート、ビット数、モノラルかステレオか、パック、タグです。BPM とキーは、ファイル名に書いてあるときだけ読みます（Splice のファイル名の書き方を読み取ります）。

一覧で文字のキーを押すと、その文字で始まるサンプルへ移ります（一覧のふつうの動きです）。

6.3 お気に入り

一覧でサンプルを選び、コマンド+D でお気に入りに入れます。もう一度押すと外れます。入れると、全部で何件あるかを読み上げます。「お気に入りだけを表示」を入れているときに外すと、その行は一覧から取り除きます。

6.4 読み取り先とパックへすぐ移る

  • コマンド+1 で「すべての読み取り先」、コマンド+2 から先で、登録した順の読み取り先に切り替えます。切り替えると、そのまま検索し直して件数を読み上げます
  • コマンド+P でパックの選択肢へ移ります。上下矢印で選んでから、タブを 4 回押して「検索を実行」へ移り、リターンを押すと探します（パックを選んだだけでは検索し直しません）

7. 試聴する

検索結果一覧でスペースを押すと鳴ります。もう一度押すと止まります。別の行でスペースを押すと、その音に切り替わります。

音量はコマンド+上矢印・コマンド+下矢印で 10% ずつ変えます（一覧にいるまま変えられます）。いまの音量を読み上げ、端まで来ると「これ以上上げられません」と添えます。タブで「試聴の音量」の選択肢へ移って選ぶこともできます。音量は覚えておき、次に開いたときも同じです。初めは 70% です。

文字を打つ欄にいるときのコマンド+上下矢印は、文頭・文末への移動になります（音量は変わりません）。

8. Pro Tools へ置く

8.1 置き方

  1. Pro Tools でセッションを開き、置きたい場所に編集カーソルを置きます
  2. 置く先のオーディオトラックを決めます。Pro Tools でトラックを選ぶか、アプリでコマンド+T（8.2）を使います
  3. アプリの一覧でサンプルを選び、リターンを押します。短い音のあとに「Pro Tools へ配置しています」と読み、終わると結果を読み上げます

成功すると「[情報] 配置しました。ファイル名、トラック「Audio 1」、位置 …」のように読みます。Pro Tools が前に出てくることはありません。アプリにいるまま、次の素材を選んで置けます。

置くには、Pro Tools が起動していて、セッションが開いている必要があります。アプリは Pro Tools に直接つながります（Pro Tools の PTSL という仕組みを使います）。

8.2 置く先のトラックをアプリで決める（コマンド+T）

画面を見ずに Pro Tools でトラックを選ぶのは手間で、選び損ねると置けません。コマンド+T を押すと、いま開いているセッションのオーディオトラックの一覧が出ます。上下矢印で選んでリターンを押すと、以後はそのトラックへ置きます（Pro Tools で何を選んでいても関係なくなります）。

一覧の先頭の「Pro Tools で選んでいるトラック（指定しない）」を選ぶと、指定を外します。指定は、アプリを閉じるまで覚えています。セッションを開き直してそのトラックが無くなっていたら、いまあるトラックを読み上げて、選び直すように言います。

8.3 置けないとき

  • オーディオトラック以外には置けません。インストゥルメント・AUX・マスターのトラックを選んでいると、「いま選ばれているのは「Inst1」で、オーディオトラックではありません。「Audio 1、Audio 2」のどれかを選んでから…」のように、何を選べばよいかまで読み上げます
  • チャンネル構成が違っても置けます。Pro Tools は、モノラルの素材をステレオのトラックに置かせてくれないので、アプリが素材のほうを変えてから置きます。モノラルからステレオは、同じ音を左右に分けるだけなので音は変わりません。ステレオからモノラルは左右を混ぜるので、音が変わる旨を読み上げます。変えるには ffmpeg が要ります
  • 置いたあとで、実際にどこに置かれたかを確かめます。Pro Tools は、指定したトラックに置けないとき、黙って別のトラックに置くことがあります。そのときは取り消して、警告を読み上げます。確かめられなかったときも取り消して、「置けたかどうかを確認できなかったため、取り消しました」と読みます

8.4 拍に合わせる

編集カーソルが拍の上からずれていると、置いた音がメトロノームと合いません。初めの設定では、カーソルがいちばん近い拍に合わせて置き、動かした量を「カーソルが拍から外れていたため、187 ミリ秒前の拍に合わせました」のように読み上げます。カーソルの位置にそのまま置きたいときは、セッションの条件（コマンド+S）の「カーソルの位置を拍に合わせる」を外します。

9. セッションに合わせて加工する

コマンド+S で「配置先セッションの条件」を開き、Pro Tools のセッションのテンポとキーを入れておくと、置くたびに素材をそれに合わせて加工してから置きます。素材の BPM とキーは、ファイル名から読みます（読めない素材は、その項目を合わせずに置きます）。

  • テンポ: テンポの欄の次の「いま開いているセッションのテンポを読み取って上の欄に入れる」のボタン（画面の文字は「Pro Tools からテンポを取得」）で、開いているセッションのテンポを読み取って入れられます。手で入れた値がセッションと違うと、素材が違う長さになるので、取得して使うのが確実です。空欄にすると、長さは合わせません
  • キー: 上下矢印で音を選び、左右矢印でメジャーとマイナーを切り替えます（切り替えた内容を読み上げます）。「指定しない」にすると、移調しません。キーが空のときは、一覧で選んでいた素材のキーが初めから入っています
  • この条件で試聴: 「いま入力している条件で選択中のサンプルを加工して鳴らす」のボタン（画面の文字は「この条件で試聴 再生/停止」）で、いま入れている条件で加工した音を鳴らします。もう一度押すと止まります。コントロール+シフト+L でも同じです。何をしたか（「4 半音上げ、尺を 0.750 倍に加工しました」）を読み上げます。加工には数秒かかることがあります
  • 配置のときに自動で加工する: 外すと、テンポとキーを入れたままでも加工しません

リターンで決定、エスケープで何も変えずに戻ります。テンポなどの入力が正しくないときは、理由を言ってその欄へ戻ります。

テンポとキーは、アプリを閉じると空に戻ります

セッションごとに違う値なので、次に別のセッションで作業するときに前の値のまま置いてしまわないためです。配置のしかた（位置・個数・間隔・拍に合わせるか）と試聴の音量は残ります。

入れたテンポが、いま開いているセッションのテンポと違うときは、置かずに「[警告] 設定のテンポ 130 は、セッションの 160 と違います…」と読み上げます。

9.1 位置を指定する・ループを並べる

同じ画面の「配置のしかた」で決めます。

  • 編集カーソルの位置に置くを外すと、「位置」の欄の小節・拍に置きます。17|1|000 のように、小節・拍・ティックを縦棒で区切って入れます（17|1 でもかまいません。日本語入力のまま全角で打っても読めます）
  • 並べる個数を 2 以上にすると、「間隔」の小節数おきに並べて置きます（最大 128 個）。間隔を小節で数えるので、テンポが要ります
  • 素材が間隔より長いと、あとから置いた音が前の音に重なって、前の音の終わりが切れます。そのときは、置いたあとにその旨を読み上げます

コマンド+S の「配置先セッションの条件」の画面に並ぶ項目です。タブで止まる順に、VoiceOver が読む名前の最初の文と、アプリを初めて開いたときの値を書きました。表は 14 行で、列は「読み上げられる名前」「種類」「初めの値」の 3 つです。

10. タグ・カテゴリ・種別を直す

一覧でサンプルを選び、コマンド+E で編集の画面を開きます。タグ（カンマで区切って複数）、カテゴリ、種別（ワンショット・ループ・種別不明）を直して、リターンで保存します。保存すると、一覧のその行を書き換えて読み上げます。

種別はスキャンのときにファイル名から推し量っただけなので、違っていたらここで直します。

14. 困ったとき

「Pro Tools につながりませんでした」と言われる

Pro Tools が起動しているか、セッションが開いているかを確かめます。Pro Tools を開いた直後は、つながるまで少し時間がかかることがあります。Pro Tools 2025.6 より前の版では置けません。

「配置できるトラックが選ばれていません」と言われる

読み上げで挙げたオーディオトラックのどれかを Pro Tools で選ぶか、アプリのコマンド+T で置く先を決めてから、もう一度リターンを押します（8 章）。

「設定のテンポ … は、セッションの … と違います」と言われる

コマンド+S で、テンポの欄の次のボタン（「いま開いているセッションのテンポを読み取って上の欄に入れる」）を押し、テンポを入れ直してから置きます。

「ffmpeg も rubberband も入っていないため…」「加工に失敗したため配置しませんでした」と言われる

3.3 のとおりに Homebrew で ffmpeg を入れ、アプリを開き直します。加工に失敗したときは、意図しない音程や長さで置かないよう、何も置かずに止めます。

「ファイルが見つかりません」と言われる

スキャンしたあとで、ファイルを動かしたか消したときに起きます。外付けのドライブなら、つないでから試します。ファイルを動かしたときは、動かした先のフォルダを読み取り先に登録して、スキャンし直します。

スキャンしても音が増えない・「フォルダが存在しません」と言われる

読み取り先のフォルダが外付けのドライブにあるなら、つないでからスキャンします。書類・デスクトップ・ダウンロードのフォルダは、macOS の許可が要ります（3.4）。許可をしなかったときは、システム設定の「プライバシーとセキュリティ」→「ファイルとフォルダ」で、PTサンプルマネージャ のスイッチを入れます。

読み上げが聞こえない

VoiceOver が入っているかを確かめます。いちばん下の状態の表示に、最後の結果の文が出ています。

それでも分からないとき

記録（~/Library/Logs/SampleManager.log）に、アプリが起動した日時と、出たエラーが残っています。

15. 取り除き方

  1. アプリを終了し（コマンド+Q）、アプリケーションフォルダの「PTサンプルマネージャ.app」をゴミ箱へ入れます
  2. ライブラリと設定を消すなら、~/Library/Application Support/SampleManager をゴミ箱へ入れます。記録は ~/Library/Logs/SampleManager.log です

Pro Tools のセッションに置いた音は、セッションのフォルダに写しがあるので、アプリを取り除いても鳴ります。

16. できないこと・気をつけること

  • Intel の Mac では動きません。Pro Tools は 2025.6 以降が要ります
  • 置けるのはオーディオトラックだけです
  • 素材の BPM とキーは、ファイル名から読みます。名前に書かれていない素材は、テンポとキーを合わせられません
  • スキャンしたあとで消したり動かしたりしたファイルは、一覧から自動では消えません。その読み取り先を外してから、登録し直してスキャンすると、いまあるものだけになります（お気に入りやタグは、その読み取り先の分が消えます）
  • 途中でテンポが変わるセッションでは、拍に合わせる位置が、先頭のテンポで数えた近い拍になることがあります。カーソルがちょうど拍の上にあるときは動かしません
  • 置いたかどうかの確認は、トラックにそのファイル名を含むクリップがあるかで見ています。同じ素材をすでに置いてあるトラックでは、確認が甘くなります
  • 置いた音は、あとで Pro Tools のテンポを変えても追いかけません
  • 画面と読み上げの言語は日本語と英語です。ほかの言語の Mac では英語で出ます
