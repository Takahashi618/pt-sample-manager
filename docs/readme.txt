■ これは何か

Splice や自分のフォルダのオーディオサンプルを、検索して、試聴して、
Pro Tools のトラックへ置くアプリです。置く前に、素材をセッションの
テンポとキーに合わせて加工することもできます。
VoiceOver とキーボードだけで使えるように作っています。

■ 動く環境

- Apple シリコン（M1 以降）の Mac。macOS 15 以降（作者は 15.7.8 で確かめています）
- Pro Tools 2025.6 以降（置く機能に要ります。作者は 2026.4.1 で確かめています）
- VoiceOver
- 画面と読み上げの言語は、Mac の言語の設定に合わせます（日本語か英語。マニュアルの 2 章）
- テンポとキーを合わせる機能と、モノラルとステレオを変える機能には
  ffmpeg が要ります（Homebrew で入れます）。rubberband もあれば、音質が上がります

■ 入れ方（短く）

1. このフォルダの「PTサンプルマネージャ.app」を、アプリケーションフォルダへ移します
2. 開きます。初めて開くとき、macOS が開くのを止めることがあります。
   開き方は、マニュアルの「3.2 初めて開くとき」にあります
3. コマンド+F でサンプルのフォルダを登録し、コマンド+R でスキャンします

詳しくは「マニュアル.html」（または「マニュアル.txt」）を読んでください。
アプリの中では、コマンド+シフト+K でキー操作の一覧を開けます。
